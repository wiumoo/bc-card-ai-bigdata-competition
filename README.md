# BC 히든픽 v1

공모전 기획안과 아이디어 체험 앱입니다.

## 폴더 구조

```text
.
├── BC히든픽_공모전기획서_v6.pdf
├── 히든픽/
│   ├── 히든픽_체험앱.html
│   ├── 히든픽 시작.bat       # Windows 실행
│   └── 히든픽 시작.command   # Mac 실행
└── README.md
```

## 실행 방법

1. GitHub에서 **Code → Download ZIP**으로 내려받고 압축을 풉니다.
2. `히든픽` 폴더에서 실행합니다.
   - **Windows:** `히든픽 시작.bat` 더블클릭. 설치된 Edge 또는 Chrome으로 열립니다.
   - **Mac:** `히든픽 시작.command` 더블클릭. Safari로 열립니다.
3. 실행기 대신 `히든픽_체험앱.html`을 PC 브라우저로 직접 열어도 됩니다.

실행기와 HTML은 같은 폴더에 두세요. 별도 패키지 설치나 서버 실행은 필요 없습니다.
