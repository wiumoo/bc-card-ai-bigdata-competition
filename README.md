# BC 히든픽

BC 소비데이터를 활용한 공모전 기획서와 아이디어 체험 앱입니다.

## 폴더 구조

```text
공모전/
├── BC히든픽_공모전기획서.pdf
├── BC히든픽_요약서.pdf
├── 히든픽/
│   ├── 히든픽_체험앱.html
│   ├── 히든픽 시작.bat
│   └── 히든픽 시작.command
└── README.md
```

## 실행 방법

1. `히든픽` 폴더에서 실행합니다.
   - **Windows:** `히든픽 시작.bat` 더블클릭. Edge 또는 Chrome으로 열립니다.
   - **Mac:** `히든픽 시작.command` 더블클릭. Safari로 열립니다.
   - 실행기 대신 `히든픽_체험앱.html`을 PC 브라우저로 직접 열어도 됩니다.
2. 앱의 **“3분, 이야기 따라가기”**로 제안·참여·혜택·결제 체험을 시작합니다.

실행기와 HTML은 같은 폴더에 두세요. 별도 설치나 서버가 필요 없는 가상 시연이며, 실제 결제나 제휴 발송은 일어나지 않습니다.
