# BC 히든픽

> 검색에는 잘 드러나지 않지만 실제 결제가 활발한 지역 가맹점을, BC카드 소비데이터로 발견하고 방문객에게 연결하는 데이터 기반 제휴·마케팅 서비스

이 저장소는 **제1회 AI금융빅데이터플랫폼 소비데이터 활용 아이디어 공모전** 출품작인 **BC 히든픽**의 최종 기획서와 체험용 데모 앱을 담고 있습니다.

## 프로젝트 개요

맛집과 매장을 찾을 때 검색·리뷰·생성형 AI 추천에 노출되는 일부 유명 가맹점으로 선택이 집중됩니다. 반면 실제 결제는 활발하지만 온라인 정보가 부족한 지역 가맹점은 소비자에게 발견되기 어렵습니다.

BC 히든픽은 BC카드가 보유한 소비데이터를 활용해 이러한 가맹점을 발굴하고, 해당 지역을 방문한 고객에게 앱 알림과 할인 혜택으로 연결하는 서비스입니다.

### 서비스 흐름

1. **히든 매장 발굴** — 결제금액과 결제건수 등 실제 소비지표를 바탕으로 숨은 우수 가맹점을 찾습니다.
2. **제휴 제안** — BC카드가 선정된 가맹점에 히든픽 참여와 할인 혜택 제공을 제안합니다.
3. **방문객 인식** — 거주지와 결제지역의 차이를 활용해 해당 상권을 방문한 고객을 식별합니다.
4. **맞춤 추천** — 방문객에게 BC카드 앱 알림으로 인근 히든픽 매장과 혜택을 안내합니다.
5. **방문·결제** — 고객의 실제 방문과 BC카드 결제로 연결합니다.

후기 작성을 할인 조건으로 요구하지 않으며, 웹사이트 제작이나 리뷰 관리 같은 GEO 컨설팅은 서비스 범위에 포함하지 않습니다. 핵심은 **BC카드만의 결제데이터를 활용한 가맹점 발굴과 고객 연결**입니다.

## 데모 앱

체험 앱은 BC 히든픽의 사용자 경험과 서비스 흐름을 직접 살펴볼 수 있도록 만든 **단일 HTML 데모**입니다. 별도 패키지 설치, 빌드 또는 서버 실행 없이 PC 브라우저에서 사용할 수 있습니다.

### 실행 방법

저장소를 다운로드하거나 clone한 뒤 아래 방법 중 하나로 실행합니다.

- **Windows:** `히든픽/히든픽 시작.bat`을 더블클릭합니다. 설치된 Edge 또는 Chrome으로 열립니다.
- **macOS:** `히든픽/히든픽 시작.command`를 더블클릭합니다. Safari로 열립니다.
- **직접 실행:** `히든픽/히든픽_체험앱.html`을 PC 브라우저로 엽니다.

> 실행 파일과 HTML 파일은 같은 `히든픽` 폴더에 두어야 합니다.

## 활용 데이터

공모전 제공 데이터인 전국 시군구·업종별 BC카드 소비 집계데이터를 기반으로 기획했습니다. 주요 분석 항목은 기준년월, 지역, 성별, 연령대, 업종, 결제금액, 결제건수입니다.
